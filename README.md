# Suraksha Call — Live Scam Call Detector 🛡️

> **"Scam ko number se nahi, baaton se pehchano."**

A professional cybersecurity application (Web + Mobile) that detects fraudulent calls by analyzing conversations in **Hindi, English, and Hinglish** using AI.

---

## 🌟 Key Features

- 🎙️ **Live Call & Microphone Recording** — Record suspicious calls in real-time
- 📁 **Audio Upload** — Analyze WAV, MP3, WebM audio files
- 🤖 **AI Scam Detection** — Semantic scam reasoning powered by Gnani AI
- 📝 **Live Hinglish Transcript** — Speech-to-text via Gnani AI Prisma with real-time scam keyword highlighting (OTP, CBI, Arrest, KYC, Bank Account, Aadhaar)
- 📊 **Circular Risk Meter (0–100)** — Visual gauge indicating Safe (0–39), Suspicious (40–79), and High Risk (80–100)
- 📈 **Dynamic Risk Timeline** — Progressive risk chart with trigger events
- 🔴 **High-Risk Warning Banner** — Automatic alert at 80%+ with haptic feedback & sound
- 🔊 **Hindi Voice Warning** — Automatic voice alerts generated by Gnani AI Timbre
- 👨‍👩‍👧 **Emergency Family Alert** — Instant notification dispatch to emergency contacts via WhatsApp deep-link & SMS
- 🔐 **Full Authentication Suite** — Secure JWT authentication (access + refresh tokens), bcrypt password hashing, and user profile management
- 📱 **Cross-Platform Mobile App** — React Native + Expo app with bottom tabs, elderly-friendly large typography, and Hindi/English toggle
- 🛡️ **Guest / Demo Mode** — Works out-of-the-box with built-in scam and normal call simulations

---

## 🚨 Detected Scam Types

1. **Digital Arrest Scam** (Fake CBI, Police, Supreme Court or Customs impersonation)
2. **Fake KYC Scam** (SIM deactivation, Bank KYC update threats)
3. **Bank OTP / Account Takeover Scam**
4. **Lottery & Prize Scam** (KBC, lucky draw fraud)
5. **Urgent Financial Demands & Threats**
6. **Secrecy Demands & Psychological Coercion**

## 🚀 Getting Started

### Prerequisites
- **Python 3.11+**
- **Node.js 18+**
- **Expo Go app** on your phone (for mobile testing) or Android Studio emulator

---

### 1. Backend Setup

```bash
cd backend
python -m venv venv

# Windows
.\venv\Scripts\activate
# Linux/macOS
source venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
# Edit .env and insert your GNANI_API_KEY if available (optional, demo mode works without it)

uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
API Documentation will be live at: `http://localhost:8000/docs`

---

### 2. Web Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
Web dashboard will be live at: `http://localhost:5173`

---

### 3. Mobile App Setup (React Native + Expo)

```bash
cd mobile
npm install

# Start Metro Bundler
npx expo start

# To test on Android Emulator
npx expo start --android

# To build standalone Android APK with EAS
npx eas-cli build --profile preview --platform android
```

---

## 🔒 Security Best Practices

- **Zero Client-Side API Keys:** Gnani AI credentials are strictly confined to the backend server and never exposed to the web or mobile clients.
- **Token Protection:** Mobile app stores JWT tokens in encrypted hardware-backed storage via `expo-secure-store`.
- **Database Isolation:** User emergency contacts and call history are partitioned per user ID with optional guest isolation.
